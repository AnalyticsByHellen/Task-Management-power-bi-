# Task-Management-power-bi-
I was asked to assess NovaTech Solutions’ task management data to identify project performance, task completion, workload distribution, productivity, risks, and delivery trends. I analyzed 1,000 tasks using Power BI to transform operational data into clear insights that support better project monitoring and decision-making.

📊 Project Overview

This was my first paid data analytics project, completed for NovaTech Solutions. I was asked to assess the company’s task management data and turn operational data into clear, actionable insights for monitoring projects and team performance.

Using Power BI, I analyzed 1,000 task records to understand project progress, workload, productivity, priorities, risks, and task completion.

🎯 Objectives

The analysis focused on:

Tracking overall task completion and project progress
Identifying completed, in-progress, overdue, and not-started tasks
Analyzing workload across employees and departments
Comparing estimated vs. actual working hours
Monitoring high-priority and high-risk tasks
Comparing performance across projects
Identifying patterns in task completion and delivery
🛠️ Tools Used
Power BI
DAX
Data cleaning and transformation
Data visualization
KPI development
📈 Dashboard

The Power BI dashboard includes:

Executive Overview

Task & Status Analysis
Employee/Workload Analysis
